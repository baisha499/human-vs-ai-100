# 人机测试 100 关 · Human vs Bot 100

一个纯前端、零依赖的「人机验证（CAPTCHA）闯关」小游戏。参考 Cloudflare Turnstile、Google reCAPTCHA、Steam 登录验证等真人检测思路，把常见的人机验证方式做成 100 个由易到难的关卡。你要一路通过验证，向系统证明「你是人类，不是机器人」。

## 玩法

- 共 **100 关**，每关都是一种真人验证挑战，一关比一关难。
- 验证通过自动进入下一关；失败则本关重试。
- 进度自动保存在本机浏览器（localStorage），关掉再打开会停在最高解锁处。
- 已解锁的关卡可在下方选关网格中直接进入；支持 `#关卡号` 直达，例如 `index.html#23`。
- 通关全部 100 关即通过终极人机测试。

## 8 类验证挑战（按关循环轮换，参数随等级递增）

| 类型 | 玩法 | 难度递增方式 |
|---|---|---|
| 按住复选框 | 按住「我不是机器人」直到进度条走完，瞬间打勾判为机器人 | 按住时长 1→3 秒，后期要求自然微小位移 |
| 点选图片网格 | 选出所有指定类别的图标格子 | 网格 2×2→4×4，后期加噪声点、模糊 |
| 辨认扭曲字符 | 从干扰线条和扭曲中读出字符 | 长度 4→8，扭曲/旋转/噪声增强 |
| 滑块拼图对齐 | 拖动滑块对齐白色缺口 | 允许误差逐渐缩小 |
| 顺序点击 | 按数字升序 / 字母 A-Z / 数字降序依次点击 | 个数 3→8，规则由易到难 |
| 口算验证 | 心算算式并填答案 | 加减→乘除→两步混合 |
| 轨迹判别人/机 | 判断轨迹是人类（自然抖动曲线）还是机器人（匀速直线） | 后期机器人加入微抖动更迷惑 |
| 旋转转正 | 把倾斜图案转回正立 | 角度容差 24°→5° |

## 目录结构

```
human-vs-ai-100/
├── index.html          # 入口页面
├── css/
│   └── style.css      # 样式（CAPTCHA 卡片风格，手机/电脑自适应）
├── js/
│   ├── levels.js      # 100 关难度曲线、题目生成、答案判定（level 作随机种子，同关题目稳定）
│   ├── challenges.js  # 8 类挑战的渲染与交互（兼容鼠标/触摸）
│   └── game.js        # 引擎：关卡推进、本地存档、选关、判定反馈
└── README.md
```

## 本地运行

无需构建、无需安装依赖。任选一种：

```bash
# 方式一：直接双击打开 index.html
# 方式二：起一个静态服务
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000/
```

## 部署到 GitHub Pages

1. 把仓库推送到 GitHub；
2. 仓库 **Settings → Pages → Source** 选择 `main` 分支根目录；
3. 稍等即可通过 `https://<用户名>.github.io/human-vs-ai-100/` 访问。

## 技术说明

- 原生 HTML / CSS / JavaScript，无任何框架、无外部图片或接口，可离线运行。
- 题目由 `level` 作为随机种子离线生成，同一关每次进入题目一致，便于重试与测试。
- 所有交互同时支持鼠标指针与触屏 Pointer Events。
